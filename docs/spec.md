# step_recorder 仕様書

Windows 標準の「ステップ記録ツール」を拡張したツール。GUI ソフトウェアの開発後に、企画チームへエビデンスとして渡す「操作記録」を作る作業を省力化する。

## 1. 全体の流れ

1. 対象(モニター、またはアプリ)を選んで記録を開始する
2. 対象を操作する。設定した撮影モードに従ってスクリーンショットと操作内容が記録される
3. 記録を停止すると編集画面が開く。削除・並べ替え・説明文の修正などを行う。編集画面はマウスカーソルのあるモニターの真ん中に、作業領域に収まる大きさで開く
4. 保存すると `session.json`(正となるデータ)とプレビュー用 HTML を書き出す
5. 後日 `session.json` をツールで開けば再編集できる
6. 編集画面の「続けて記録」で、同じ記録の続きを記録できる(3.7)

## 2. 技術構成

| 項目 | 内容 |
|---|---|
| 言語・UI | C# / WPF (.NET 10)。見た目は WPF 標準の Fluent テーマ(明るい配色。記録中のバーだけ暗い配色)。録画は Windows.Graphics.Capture と Media Foundation(WinRT の MediaTranscoder・MediaComposition)、Direct3D 11 は Vortice.Direct3D11 |
| 対象アプリ | WinForms / WPF (.NET) を主に想定。UI Automation で部品名を取得する |
| 配布・更新 | Velopack + GitHub Releases(public リポジトリ `taaaaaaachu/step_recorder`)。起動時に更新を確認する(設定でオフにできる)。開始画面の「今すぐ確認」で手動でも確認でき、こちらは最新のときや失敗したときも結果を出す。マニフェストでコモンコントロール v6 を使う(WinForms の EnableVisualStyles 相当) |
| 言語 | 日本語のみ |
| テスト | xUnit。記録ロジック・生成処理・JSON の読み書きを単体テストする |

## 3. 記録

### 3.1 撮影範囲

開始画面の「対象」に、モニター(「画面 2  1920×1080(メイン)」)とアプリを並べる。どちらを選んでも、撮影モード(3.2)と録画ボタンはすべて使える。

#### 3.1.1 アプリが対象

- 記録開始時に選んだアプリのウィンドウだけを撮る。**同じ exe(フルパス)のプロセスは 1 つのアプリとみなす**(タブやウィンドウごとにプロセスが分かれるサクラエディタのようなアプリのため)
  - 別々に起動した同じ exe も一緒に記録される
  - 中身の違うアプリが同じ exe で動く共通のホスト(ApplicationFrameHost、java、python、dotnet、cmd など。`SharedHost`)と、exe のパスが取れないプロセスは、プロセス単位
  - 選んだプロセスのウィンドウが隠れている・終了していても、同じアプリの見えているウィンドウから記録する
- 対象の一覧は、開くたびと開始画面に戻ったときに作り直す(選んだものは残す)
- 撮るのは対象アプリのウィンドウ。ダイアログや子ウィンドウも含む
- 他のアプリや通知、常駐バーは写り込まない(ウィンドウ単位で撮るため)
- 画像はアプリ全体にする。対象アプリの見えているウィンドウ(メインウィンドウ・ダイアログ・メニューなど)を、Z オーダーの奥から順にすべて重ねて1枚にする。ウィンドウ同士の隙間は白。画面の外に置かれたウィンドウは含めない。Windows 11 のウィンドウの縁の線(PrintWindow では黒くなる)は写さない。モニターの拡大率と違う DPI で描くアプリ(DPI 非対応・システム DPI 対応)は、画面に見えている大きさに縮めて(伸ばして)写す
- 操作したウィンドウ(クリックしたウィンドウ、手動撮影で撮った前面のダイアログなど)がアプリ全体より小さいときは、そのウィンドウの範囲をトリミングとして設定する。元画像はアプリ全体のまま残るので、編集画面でトリミングを外せば周りも見える

#### 3.1.2 モニターが対象

- モニターの番号は左から右(同じ列なら上から下)の順に振る(Windows の設定画面の番号とは一致しないことがある)。一覧で選ぶと、そのモニターに赤枠と番号を 1.5 秒出す(最初からそのモニターに出す)
- そのモニターに見えているものを丸ごと撮る(他のアプリ・タスクバー・通知も写る)
- そのモニターの上での操作を、どのアプリへのものでも記録する。クリックは押した位置、キーは前面のウィンドウが載っているモニター(またがっていれば広く載っている方)で決める。他のモニターでの操作と、step_recorder 自身への操作は記録しない
- 操作したウィンドウの範囲(モニターに載っている分)をトリミングとして設定する。範囲が取れないとき(デスクトップなど)はトリミングしない
- 手動撮影と録画ボタンは、前面のウィンドウが他のモニターにあっても、対象のモニター全体を撮る
- 画面名の初期値は操作したウィンドウのタイトル。タイトルが無ければ(タスクバーなど)「画面 2」
- 常駐バー・進み具合のウィンドウ・赤枠は写らない(画面には見えたまま、取り込みから外す)
- 制限
  - 入力内容は欄の値全体を読むので、どのアプリに打ったものも記録に残る(エディターなどでは文書の全文が入りうる)。伏せるのはパスワード欄だけ
  - UAC の画面と保護されたコンテンツは黒くなる。管理者権限のアプリへの操作は拾えない
  - 記録中の解像度の変更・切断には追従しない
  - HDR のモニターは色が変わりうる(8bit で取り込むため)
  - Windows 10 では、録っている間モニターに黄色い枠が出ることがある(動画には写らない)

#### 3.1.3 共通

- マウスカーソルは既定では写さない。設定で「写す」にすると、撮影した瞬間のカーソルを画像に重ねて描く(クリックごとモードでは、クリックした位置にカーソルが写る)
- Per-Monitor DPI 対応。マルチモニターと拡大率の違いを考慮して座標を扱う

### 3.2 撮影モード

| モード | 撮るタイミング |
|---|---|
| クリックごと | 対象(アプリのウィンドウ、またはモニター)の上でマウスボタンを押した瞬間(クリック前の状態を撮る) |
| 手動 | ホットキーまたは常駐バーの撮影ボタンを押したとき |
| 録画 | クリックごとと同じに撮りつつ、記録の最初から最後までを動画に録る(3.6.2) |

- クリックごと・手動は記録中に常駐バーで切り替えられる。録画は記録の開始時に選ぶ(全編を録るため途中では切り替えない)
- どのモードでも手動撮影は常に使える
- クリック操作を記録するのは「クリックごと」「録画」のときだけ。キー入力はどのモードでも直近のステップに記録する
- ダイアログなどが出たときは、手動撮影で撮る(前面のウィンドウを撮り、そのウィンドウの範囲をトリミングにする)
- ダブルクリックは新しいステップにせず、直前のクリックを「ダブルクリック」に変える

### 3.3 記録する操作情報

各ステップに以下を記録する。

- 撮影時刻、撮影モード(どの契機で撮ったか)
- ウィンドウ: タイトル、クラス名、プロセス名
- 操作した部品(取れた場合): 名前、コントロール種別、AutomationId、画像内の矩形
- クリック: ボタン(左/右/中)、ダブルクリックか、画像内の座標
- キー入力: 入力欄の名前と入力内容
  - 入力内容は部品の値(UI Automation の ValuePattern)から取る。IME で確定した日本語も取れる
  - 文字を入力した欄の値は、次のクリック・次のキー操作・入力が 1.5 秒止まったとき・記録停止のいずれかで読み取る
  - 同じ欄への連続した入力は1つの操作にまとめる
  - 矢印・Home・End・PageUp・PageDown・Insert はカーソル移動とみなし、入力として扱わない
  - パスワード欄(IsPassword)は `●●●●` に伏せる
  - Enter・Tab・Esc や Ctrl+S などのショートカットは「キー操作」として別に記録する
  - ブラウザー・音量・メディアなどの専用のキー(「ブラウザーの戻る」「音量 +」「再生/一時停止」など)もキー操作として記録する。多ボタンマウスの 6 個目以降のボタンは、付属のソフトがキーに置き換えて送るので、割り当てたキーとして記録される(付属のソフトの中で済む操作は Windows に届かないので記録できない)
  - IME が開いているときの Enter・Esc は変換の確定・取消とみなし、キー操作として記録しない(IME を開いたまま押した送信の Enter は記録されないので、必要なら編集画面で書き足す)
  - 記録用のホットキー自体は記録しない

### 3.4 自動生成する説明文

部品情報から説明文を作る。例:

- 「『保存』ボタンをクリック」
- 「『氏名』欄に「山田太郎」と入力」
- 「Ctrl+S を押す」
- 部品名が取れない場合: 「(120, 45) をクリック」
- 手動: 空欄(編集画面で入力する)

### 3.5 記録中の操作

- 最前面に小さな常駐バーを出す(最初は対象のあるモニター(アプリならそのウィンドウがあるモニター)の上端中央。ドラッグで動かせる)。表示内容: 撮影モードの切替(2 つを並べた切り替え)、手動撮影、録画(録画中は経過時間)、一時停止/再開、停止(赤く塗る)、撮影済み枚数。ボタンはアイコン付きの平らなボタン(乗せると明るくなる)
- 常駐バーは使っていない間、小さなタブに引っ込む
  - 記録を始めたときは 2.5 秒見せてから引っ込める。タブに 0.15 秒マウスを乗せると出て、離れて 0.8 秒で引っ込む
  - マウスのボタンを押したまま(ドラッグで)タブの上を通っても出さない。タブを押したとき(タッチ・読み上げ)は 2.5 秒出す
  - 引っ込んだ所は、バーの上端・左右の中央。ドラッグで動かしたら、その場所で引っ込む
  - バーの右端のピンを押すと(赤くなり、ピンの針が真下を向く)、引っ込まなくなる。もう一度押すと外れ、マウスが離れて 0.8 秒で引っ込む。ピンは記録のたびに外れた状態で始まる
  - 開閉は滑らせる: 引っ込むときはバーが上端へ 0.18 秒で消えてからタブが下りる。出るときは上端から 0.22 秒で下りてくる(途中で逆向きにもなる)。Windows の「アニメーション効果」を切っていれば、すぐに入れ替える
  - バーの周りの透明な所のクリックは、下のアプリへ通る
  - タブで状態が分かる: 赤 ● 記録中、赤 ■ 動画のステップを録画中、灰 ❚❚ 一時停止。ホットキーは引っ込んでいても効く(バーは出さない)
- 既定のホットキー(設定で変更可)
  - 手動撮影: `Ctrl+Shift+F9`
  - 一時停止/再開: `Ctrl+Shift+F10`
  - 停止: `Ctrl+Shift+F11`
  - 録画の開始/停止: `Ctrl+Shift+F12`
- ホットキーの設定は、欄をクリックすると入力待ちになり、押した組み合わせ(Ctrl・Alt・Shift・Win のいずれかと他のキー)がそのまま入る。修飾キーだけ・修飾キーなしは受け付けない。Esc で取り消し。4つに同じキーは設定できない
- 一時停止の間は操作も動画(全編・動画のステップ)も録らない。止めていた時間は動画に入らず(前後がつながる)、録画の経過時間とステップの時刻の目盛りにも入らない。止める前に打った文字は、止めた時点の値で確定する。手動撮影は一時停止中も使える
- 停止すると常駐バーを消し、編集画面が開くまで進み具合を小さなウインドウで出す(「撮った画像を保存しています(残り 2 件)」→「動画を書き終えています」→「記録を保存しています」→「編集画面を開いています」)。止め終えるまでは閉じられない

### 3.6 動画

- モニターが対象なら、モニター 1 枚を丸ごと録る(Windows.Graphics.Capture)。大きさと位置は録り始めたときのもの。縮小はしない(7680×4320 までエンコードできることを確認済み)
- アプリが対象なら、録り方は OBS のウィンドウキャプチャと同じ(Windows.Graphics.Capture)。ウィンドウごとに録るので、他のアプリや常駐バーが上に重なっても写らない。ダイアログなど同じアプリのウィンドウは、静止画と同じく Z オーダーの順に重ねる。透明度を見て重ねるので、Windows 11 のウィンドウの角の丸みの外は後ろが見える(黒くならない)
- アプリが対象のとき、画面の大きさは録り始めたときのウィンドウで固定し、位置はそのウィンドウに追従する。はみ出したダイアログは切れる
  - そのウィンドウが隠れた・閉じた(タブの切り替え)ときは見えているウィンドウへ、別プロセスの同じ種類(ウィンドウクラス)のウィンドウが前面に来たときはそのウィンドウへ、追う相手を移す。大きさは変えないので、違う大きさのウィンドウは切れるか余白が出る
- mp4(H.264。音声は AAC 48kHz ステレオ)。フレームレートは開始画面で選ぶ(5・10・15・24・30・60fps。既定は 15)。エンコードは Windows 標準の機能を使う(ソフトウェアで。ハードウェアエンコーダーは小さい画面で失敗することがあるため)
- エンコーダーには NV12 に変換してから渡す(明るさ 16〜235。幅 1024・高さ 576 までは BT.601、超えたら BT.709)。Windows に変換を任せると、PC によっては明るさ 239 以上が真っ白に潰れるため。使った係数・範囲・原色を mp4 に書く(書かないとブラウザーが推測して、高さ 720 未満の動画の色がずれる)
- 動画からのフレームの取り出し(ポスター、フレームのステップ、切り出し、GIF)も、デコーダーから NV12 で受け取って自前で RGB に戻す。Windows に任せると、PC によっては HD の動画の色がずれるため
- マウスカーソルは静止画と同じ設定で写す
- 録画している間(録画モードの全編・録画ボタンの動画)は、常に PC の音も録る(WASAPI のループバック)。使うかどうかは編集画面で選ぶ(4)
  - アプリが対象なら、録り始めたときのウィンドウのプロセスと、その子プロセスが鳴らした音だけ(通知音や他のアプリの音は入らない)。モニターが対象なら PC 全体の音
  - 何も鳴っていない間は無音で埋めて、映像とずれないようにする。一時停止中の音は入らない
  - 録れなかったとき(音の出る機器が無いなど)は映像だけを録り、理由を `error.log` に残す
- Windows 10 2004 以降

#### 3.6.1 動画のステップ(録画ボタン)

- 記録中に常駐バーの「録画」かホットキー(既定 `Ctrl+Shift+F12`)で、操作しているウィンドウ(対象がモニターならモニター全体)を録り始める。もう一度押すと止まり、その間が1つの動画のステップになる(`videos/0003.mp4`)
- 録っている間は静止画を撮らず、操作(クリック・入力・キー)を動画のステップに足して説明文にする。操作が無ければ「『画面名』の操作(動画)」。操作には、押した時点の動画上の時刻を持たせる(`operations` の `videoTime`。分割で前後に振り分けるのに使う)
- ポスター(再生前に見せる画像)は動画の最初のフレーム(区間を変えたら区間の最初のフレーム)。強調枠は付けない。トリミングはできる
- 編集画面で区間を変えたり、2つに分けたりできる(4)。ファイルは切らずに区間(`videoStart`・`videoEnd`)だけを持ち、分けたステップは同じ mp4 を使う

#### 3.6.2 録画モード

- 開始画面の撮影モードで「録画」を選ぶと、記録の最初から最後までを1本の動画(`video.mp4`)に録る。続けて記録で録った分は別の全編の動画になる(`video-2.mp4`、`video-3.mp4`…)。`session.json` の `videos` に録った順に並べる
- ステップ(静止画)はクリックごとに撮り(手動撮影もできる)、各ステップに動画上の時刻を持たせる(`videoTime`。どの全編の時刻かは `timelineVideo`)
- 録画モードでは録画ボタンは使わない。編集画面で全編から区間を切り出す
- クリックが 1 回も無くても動画だけの記録として残り、編集画面は動画を出した状態で開く
- 動画を書けなかったときは全編の動画を記録に載せず(撮れたステップは残す)、`error.log` の場所を知らせる

#### 3.6.3 キーの表示

- 録画している間(録画モードの全編・録画ボタンの動画)に押したキーを、1 打鍵ずつ動画上の時刻と一緒に残す(全編は `session.json` の `videos` のその動画の `keys`、録画ボタンの動画はそのステップの `keys`)。対象(アプリ・モニター)へのキーだけで、記録用のホットキーと一時停止中のキーは残さない
- 表記: 修飾キーと一緒なら「Ctrl+S」、文字は打った文字そのもの(キーボードの配列・Shift・CapsLock を効かせる。IME が開いていればローマ字の打鍵)、それ以外は「Enter」「Shift+Tab」「←」など。修飾キーだけの打鍵は出さない
- パスワード欄で打った文字は「●」に伏せる
- 表示: 続けて打った文字は 1 つにまとめ(1 秒空いたら分ける。末尾の 24 文字まで)、同じキーの連打は「← ×3」にまとめる。最後に押してから 1.5 秒出し、同時に出すのは新しい 3 つまで。動画の下の中央に、新しいものほど下に積む。大きさは動画の高さに比例する(高さの 1/18。12〜44 画素)

#### 3.6.4 マウスの表示

- 録画している間のクリック(左・右・中ボタン、マウスの横の戻る・進むボタンを押したとき)とホイール(縦・横)を、動画上の時刻と位置と一緒に残す(全編は `session.json` の `videos` のその動画の `mouse`、録画ボタンの動画はそのステップの `mouse`)。拾うのはクリックを記録するのと同じ対象の上の操作だけで、動画の外(アプリのウィンドウからはみ出したダイアログなど)と一時停止中は残さない。手動撮影モードでも、録画ボタンの動画の間は残す
- 表示: クリックはその位置に、ボタンの色(左は赤・右は青・中は緑)の輪が 0.6 秒かけて広がりながら消える。輪の右下には、押したボタン(左・右・ホイール)を同じ色で塗ったマウスの絵を出す(色だけに頼らず左右を見分けられるように)。右端・下端のクリックでは、はみ出さないよう左・上に出す。ボタンを押したまま動かすと(4px より多く)、輪は押した所で消え、マウスの絵だけが離すまでカーソルについていく(押している間の位置を 1/60 秒ごとに `mouse` の `drag` に残す)。ダブルクリックは輪が 2 つ。戻る・進むボタンは紫の輪で、マウスの絵の胴に「←」「→」を描く。ホイールは暗い丸に回した向きの白い三角を出し、同じ向きに続けて回す間(0.4 秒空くまで)は 1 つにまとめて、最後に回してから 0.6 秒出す。位置は回し始めのところ
- 大きさはキーの文字の 0.8 倍の半径(見えている範囲の高さで決まる)
- ドラッグ・カーソルの軌跡は出さない(カーソル自体は「カーソルを写す」の設定で動画に入る)

### 3.7 続けて記録

- 編集画面の「続けて記録」を押すと、変更を保存して編集画面を閉じ、開始画面に戻る(保存できなければ閉じない)
- 開始画面の上に「「<対象名>」の記録に続けて記録します」と出る。対象・撮影モードなどは選び直せる。出力先は変えられない(その記録のフォルダに足す)。「編集に戻る」でその記録の編集画面に戻る。「記録を開く...」で別の記録を開いたときもやめる
- 「記録開始」で記録した分は、その記録の末尾に足す。ステップの番号・画像のファイル名は前の分の続き(前のファイルは上書きしない)。録画モードなら別の全編の動画になる(3.6.2)
- 対象名・記録日時・エビデンス情報(5.1.1)は最初の記録のまま
- 何も撮らずに止めても、記録は消さずに編集画面に戻る

## 4. 編集画面

- ステップの一覧(サムネイル + 説明文)と、選んだステップの画像
- 画像はズームできる。最初は全体が収まる大きさ(小さい画像は拡大しない)。Ctrl+ホイールでマウスの位置を中心に拡大縮小、ボタン(−・+・100%・全体)、Ctrl+プラス / Ctrl+マイナス / Ctrl+0。拡大すると縦横にスクロールでき、ホイールボタン(中ボタン)を押したままドラッグすると画像をつかんで動かせる
- 機能
  - ステップの削除(一覧を選んでいるときは Delete でも消せる。それ以外の Delete は選んだ強調枠を消す)、並べ替え
  - 説明文の修正
  - 画面名(見出し)の設定。初期値はウィンドウタイトル
  - 強調枠の移動・サイズ変更・削除・追加
  - トリミング(元画像は残し、範囲だけを持つ)
  - 元に戻す(Ctrl+Z)・やり直す(Ctrl+Y)。どちらもボタン(丸い矢印)がある。新しく変更すると、やり直せる分は消える。並べ替え・削除・文字の編集・強調枠・トリミング・動画の速さ・動画の区間と分割が対象。文字の編集は、欄で編集を始めてから終えるまでを1回分として戻す(入力中の Ctrl+Z は欄の中の取り消し)。履歴は 100 回分
- 同じ画面の扱い(設定で選ぶ)
  - 手順モード: 撮った順に並べるだけ。不要なものは人が消す
  - 画面一覧モード: 画面ごと(プロセス + ウィンドウクラス + 画面名)にまとめ、各画面の下に操作手順を並べる
    - 画像はその画面で最初に撮ったものを使う(使いたい画像を先頭に並べ替えて選ぶ)
    - 編集画面の一覧も、出力と同じまとまりで画面ごとに見出しを付けて区切る
- 動画の表示・再生も、書き出しと同じく自前で復号した画像を出す(音声は無い)。GPU ドライバーの動画の設定に左右されず、取り出したフレームと同じ色になる(MediaElement は NVIDIA の既定の設定で眠い色になる)
- 動画のステップは「▶ 再生」で区間だけを再生する。一覧には「▶ 動画」と付く
- 動画のステップごとに再生の速さの初期値を選べる(「▶ 再生」の右。0.25・0.5・0.75・等速・1.5・2・3・4・8 倍。`session.json` の `videoSpeed`。等速なら書かない)。録画ボタンで録った動画と、全編から切り出した区間の両方が対象
- 動画のステップごとにフレームレートを下げられる(「再生の速さ」の右。録画したときのフレームレート以下から選ぶ。`session.json` の `videoFps`。録画したときのままなら書かない。元に戻すの対象)。編集画面の再生はそのフレームレートのコマで見せ、配布用の書き出しはそのフレームレートで作る。保存用の HTML は録画した mp4 をそのまま再生するので変わらない
  - 速さはプレーヤーで変える。編集画面の再生と HTML(保存・配布用とも)に反映し、mp4 は等速のまま(全コマ残り、見る人が変えられる)。GIF だけはプレーヤーが無いので焼き込む
  - 一覧には「▶ 動画」の代わりに「▶ 2 倍速」のように付く。再生中に変えると、その速さで区間の最初から再生し直す
- 録画ボタンで録った動画のステップを選ぶと、表示欄の下にその動画のシークバーを出す。シークバーは動画ファイル全体で、使う区間を塗る。動かすと表示欄にそのフレームを出す(←→ でコマ送り)。再生中は再生位置を追う
  - 「開始位置」「終了位置」: 区間の開始・終了を今の位置にする。開始より後に終了が来ないとできない。開始を変えたら、ポスターもそのフレームにする
  - 「分割」: 今の位置で2つのステップに分け、後ろを選ぶ。区間の中でだけできる。画面名・速さ・トリミング・キーとマウスの表示は引き継ぐ。録画中の操作は時刻で前後に分け、説明を作り直す(手で直した説明なら両方に残す)。キーとマウスの表示はそれぞれの区間の中のものだけ出す
  - 全編から切り出した区間のステップには出さない(全編のシークバーで扱う)
- 録画モードの記録では、表示欄の下に全編のシークバーと操作ボタンを出す。シークバーを動かすか ▶ を押すと、表示欄に全編の動画を出す(ステップを選ぶとそのステップの画像に戻る)。目盛りはステップを撮った時刻で、ステップを選ぶとシークバーもその時刻へ移る
  - 全編が 2 本以上あるとき(続けて記録した記録)は、再生ボタンの左のドロップダウン(「全編 1」「全編 2」…)で、シークバーに出す全編を選ぶ。目盛りはその全編のステップだけ。別の全編のステップを選ぶと、シークバーもその全編に切り替わる。足したフレーム・区間は、出している全編のもの
  - シークバーは左右いっぱいに出し、その下の段に操作ボタン(左)と、現在時刻・拡大のボタン(右端)を並べる
  - 時刻は 0:05.0 の形で、1 時間からは 1:00:05.0 と時も出す(記録バーの録画の経過時間も同じく時を出す。こちらは秒まで)
  - シークバーは時間軸を拡大できる。Ctrl+ホイールでマウスの位置の時刻を中心に拡大縮小、ボタン(−・+・全体。現在位置を中心に)。全編が収まる幅から、1 秒分が収まる幅まで。拡大中はホイールかスクロールバーで横に動かせ、再生やステップの選択で現在位置が見えなくなるとそこへ移る
  - 「このフレームをステップに追加」: 今の時刻のフレームを静止画のステップにする
  - 「区間の開始」「区間の終了」「区間を動画ステップに追加」: 全編の区間を動画のステップにする(ファイルは作らず、区間だけを持つ)
  - 足したステップは時刻の順の位置に入る。画面名は直前のステップに合わせる
- 削除したステップや、元に戻して使わなくなった画像・動画のファイルは、保存したときに消す(全編の動画は残す)
- 動画のステップごとに、キーの表示とマウスの表示の ON/OFF を別々に選べる(「キー表示」「マウス表示」のチェック。初期値は ON。`session.json` の `hideKeys`・`hideMouse`。元に戻すの対象)。記録が無ければ押せない
- 動画のステップごとに、音を使うかを選べる(「マウス表示」の右の「音声」のチェック。初期値は ON。`session.json` の `hideAudio`。元に戻すの対象)。音の入っていない動画では押せない。編集画面の再生では、ON なら音も鳴らす(音のある動画は音の再生位置を時計にして映像を合わせるので、長く再生してもずれない。OFF でも消音で同じように合わせる)。全編の表示でも ON/OFF でき、キー表示と同じく、そこから切り出した区間のステップの初期値になる
  - 編集画面の再生では、焼き込みと同じ見た目で重ねる(キーはトリミングしていればその範囲の下)。全編の表示では、記録したものをすべて重ねる(区間を選ぶ目安)
  - 全編の表示でも 2 つのチェックで ON/OFF できる。見え方だけを変え(保存しない)、そこから「区間を動画ステップに追加」したステップの初期値になる
- 「別ウインドウで表示」で、表示欄だけを別のウインドウに出せる(別のモニターで大きく見るなど)。閉じるか「表示欄を戻す」で編集画面に戻る。別のウインドウで F か F11 を押すと、そのウインドウがある画面いっぱいに出す(タスクバーも覆う)。F・F11・Esc で元に戻る
- 記録を止めると、編集画面が前面に出る
- 未保存の変更があるまま閉じようとすると保存を確認する
- `StepRecorder.exe <記録フォルダ>` で起動すると、開始画面を出さずに編集画面を開く

## 5. 出力

### 5.1 フォルダ構成

```
<出力先>/20261121-174100_<対象名>/   対象名はプロセス名か「画面2」
  session.json     正となるデータ。ツールはこれを開いて再編集する
  index.html       プレビュー用 HTML(保存のたびに上書き)
  images/
    0001.png       撮影した元画像(加工しない)
    0002.png
  videos/
    0003.mp4       録画ボタンで録った動画のステップ
  video.mp4        録画モードで録った全編の動画(続けて記録した分は video-2.mp4 …)
```

- 出力先の既定はドキュメントフォルダ配下の `step_recorder`(設定で変更可)
- 画像は PNG。元画像は加工せず、強調枠やトリミングは `session.json` にデータとして持つ
- 「保存」は編集用(上の構成のまま。あとから編集を続けられる)。渡すときは「配布用に書き出す」(5.3)か、フォルダごと(zip など)
- 記録中の処理で起きた例外は `error.log` に書く(記録は止めない)
- `session.json` の `targetName` が対象名(操作記録の表題に使う)

### 5.1.1 エビデンス情報

HTML の冒頭に、記録した環境の情報を表で載せる。記録開始時に自動で取り、取れなかった項目は載せない。

| 項目 | 内容 |
|---|---|
| 対象アプリ | exe のファイル名(モニターが対象なら載せない) |
| バージョン | (モニターが対象なら載せない)exe の製品バージョン(無ければファイルバージョン)。.NET の SDK が付ける "+コミット" は先頭7桁に縮める |
| 記録日時 | 記録を始めた日時 |
| PC名 | 記録した PC の名前 |
| OS | OS の名前とバージョン |
| 画面 | 対象のモニター(アプリが対象なら、そのウィンドウがあるモニター)の解像度と拡大率 |
| 記録ツール | step_recorder のバージョン |

### 5.2 HTML (`index.html`)

- 画像は `images/` を相対参照する
- 強調枠とトリミングは HTML/CSS で画像に重ねて表示する
- トリミングしている画面には「トリミングを解除」ボタンを付ける。押すと画像全体を表示し、トリミング範囲の外を暗くする(編集画面と同じ見え方)。そのときボタンは「トリミングする」に変わり、押すと元に戻る
- 画像クリックで拡大表示
- 画面一覧モードで同じ画面のステップが複数あるときは、「◀ 前へ」「次へ ▶」で画面内のステップの画像を切り替えられる(位置は「1 / 3」のように出す)。今のステップの説明は太字になり、説明の行をクリックしてもそのステップへ移る
- 動画のステップは `<video>` で再生する。区間はメディアフラグメント(`video.mp4#t=開始,終了`)で指定する。再生し終えたら(区間の終わりで止まったら)、区間の最初に戻す。動画の下に「再生の速さ」の選択を出す(最初はステップに指定された速さ。見る人が変えられ、プレーヤー自体のメニューで変えても表示が揃う)。速さはスクリプトで再生速度に入れ、区間の終わりは描画ごとに見て止める(ブラウザに任せると倍速では行き過ぎる)。トリミングは CSS の `object-view-box`(Edge・Chrome。Firefox では全体が映る)。音声が OFF のステップは消音(`muted`)で始める(見る人はプレーヤーで音を出せる)
- 動画のステップでキーの表示が ON なら、再生に合わせてキーを重ねる(スクリプトで描く。動画は作り直さない)。プレーヤーの操作バーと重ならないよう、下から 56 画素より上に出す
- マウスの表示が ON なら、同じく再生に合わせてクリックとホイールを重ねる(canvas に描く。トリミングしていればその範囲での位置)
- 外部 CDN を使わず、オフラインで開ける

### 5.3 配布用の書き出し

- 編集画面の「配布用に書き出す...」を押すと、フォルダに書き出す。右の矢印を押すと、書き出し方を選ぶメニューが出る。`session.json` と全編の動画は含めない(あとから編集はできない)
  - 「フォルダに書き出す...」: 選んだフォルダに index.html と、使っている画像・動画だけを書き出す
  - 「HTML 1 ファイルに書き出す...」: 画像と動画を data: URI(base64)で埋め込んだ HTML 1 ファイルだけを書き出す(ファイル名は既定で記録フォルダの名前)。1 ファイルで渡せる代わりに、元の 4/3 倍ほどの大きさになり、ブラウザーは開くときにまとめて読み込む(長い動画が多いならフォルダに書き出す)
- 動画のステップは、区間・トリミング・キーとマウスの表示(GIF なら速さも)を反映したファイル(`clips/0003.mp4` かポスター `clips/0003.png`、または `clips/0003.gif`)に作り直す
- 動画の形式は書き出しボタンの横で選ぶ(MP4 / GIF。選んだ時点で保存し、次回はその形式になる。書き出さなくても覚える)。キー・マウスの表示が ON のステップは、それを焼き込む(GIF は縮めたあとの大きさ・位置で描く)。書き出した HTML では重ねない(焼き込み済み)。MP4 は、音声が ON なら区間の音を入れ、OFF なら入れない(GIF は音なし)。MP4 はステップのフレームレートで作る。GIF は 10fps(ステップのフレームレートがそれより低ければそれ)、幅 960px まで、繰り返し再生。スローの GIF は同じ絵を並べずに 1 コマの表示時間を延ばす
- 書き出しは裏で行い、進み具合をプログレスバーで出す(「動画を作っています(1 / 3 本目)」)。書き出し中は編集画面を操作できない。終わると書き出した index.html を開く

## 6. 設定

撮影モードの初期値(クリックごと/手動/録画)、マウスカーソルを写すか(静止画と動画)、録画のフレームレート、ホットキー、配布用の動画の形式、出力先、同じ画面の扱い(手順モード/画面一覧モード)、自動更新のオン/オフ(既定はオン。オフにすると起動時に更新を確認しない。切り替えはすぐ保存され、次回の起動から効く)。`%APPDATA%\step_recorder\settings.json` に保存する。開始画面の設定は「記録開始」のときと、開始画面を閉じたときに保存する(閉じるときは知らせを出さず、使えないホットキーと空の出力先は前のままにする)。
