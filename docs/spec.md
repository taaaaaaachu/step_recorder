# step_recorder 仕様書(ドラフト)

Windows 標準の「ステップ記録ツール」を拡張したツール。GUI ソフトウェアの開発後に、企画チームへエビデンスとして渡す「画面一覧」を作る作業を省力化する。

## 1. 全体の流れ

1. 対象アプリ(プロセス)を選んで記録を開始する
2. 対象アプリを操作する。設定した撮影モードに従ってスクリーンショットと操作内容が記録される
3. 記録を停止すると編集画面が開く。削除・並べ替え・説明文の修正などを行う
4. 保存すると `session.json`(正となるデータ)、Markdown、プレビュー用 HTML を書き出す
5. 後日 `session.json` をツールで開けば再編集できる

## 2. 技術構成

| 項目 | 内容 |
|---|---|
| 言語・UI | C# / WPF (.NET 10) |
| 対象アプリ | WinForms / WPF (.NET) を主に想定。UI Automation で部品名を取得する |
| 配布・更新 | Velopack + GitHub Releases(public リポジトリ `taaaaaaachu/step_recorder`)。起動時に更新を確認する |
| 言語 | 日本語のみ |
| テスト | xUnit。記録ロジック・生成処理・JSON の読み書きを単体テストする |

## 3. 記録

### 3.1 撮影範囲

- 記録開始時に選んだ対象プロセスのウィンドウだけを撮る。そのプロセスが開いたダイアログや子ウィンドウも含む
- 他のアプリや通知、常駐バーは写り込まない(ウィンドウ単位で撮るため)
- Per-Monitor DPI 対応。マルチモニターと拡大率の違いを考慮して座標を扱う

### 3.2 撮影モード(記録中に切り替え可能)

| モード | 撮るタイミング |
|---|---|
| クリックごと | 対象ウィンドウ上でマウスボタンを押した瞬間(クリック前の状態を撮る) |
| 手動 | ホットキーまたは常駐バーの撮影ボタンを押したとき |
| 画面切り替わり検知 | 対象プロセスの新しいウィンドウ・ダイアログが表示されたとき、または前面に来たとき。描画を待つため 300ms 後に撮る(待ち時間は設定で変更可) |

- どのモードでも手動撮影は常に使える

### 3.3 記録する操作情報

各ステップに以下を記録する。

- 撮影時刻、撮影モード(どの契機で撮ったか)
- ウィンドウ: タイトル、クラス名、プロセス名
- 操作した部品(取れた場合): 名前、コントロール種別、AutomationId、画像内の矩形
- クリック: ボタン(左/右/中)、ダブルクリックか、画像内の座標
- キー入力: 入力欄の名前と入力内容
  - 入力内容は部品の値(UI Automation の ValuePattern)から取る。IME で確定した日本語も取れる
  - 同じ欄への連続した入力は1つの操作にまとめる
  - パスワード欄(IsPassword)は `●●●●` に伏せる
  - Enter・Tab・Esc や Ctrl+S などのショートカットは「キー操作」として別に記録する

### 3.4 自動生成する説明文

部品情報から説明文を作る。例:

- 「『保存』ボタンをクリック」
- 「『氏名』欄に「山田太郎」と入力」
- 「Ctrl+S を押す」
- 部品名が取れない場合: 「(120, 45) をクリック」
- 画面切り替わり検知: 「『設定』画面が表示された」
- 手動: 空欄(編集画面で入力する)

### 3.5 記録中の操作

- 最前面に小さな常駐バーを出す。表示内容: 撮影モードの切替、一時停止/再開、手動撮影、停止、撮影済み枚数
- 既定のホットキー(設定で変更可)
  - 手動撮影: `Ctrl+Shift+F9`
  - 一時停止/再開: `Ctrl+Shift+F10`
  - 停止: `Ctrl+Shift+F11`

## 4. 編集画面

- ステップの一覧(サムネイル + 説明文)と、選んだステップの拡大表示
- 機能
  - ステップの削除、並べ替え
  - 説明文の修正
  - 画面名(見出し)の設定。初期値はウィンドウタイトル
  - 強調枠の移動・サイズ変更・削除・追加
  - トリミング(元画像は残し、範囲だけを持つ)
- 同じ画面の扱い(設定で選ぶ)
  - 手順モード: 撮った順に並べるだけ。不要なものは人が消す
  - 画面一覧モード: 画面ごと(プロセス + ウィンドウクラス + 画面名)にまとめ、各画面の下に操作手順を並べる

## 5. 出力

### 5.1 フォルダ構成

```
<出力先>/20261121-174100_<プロセス名>/
  session.json     正となるデータ。ツールはこれを開いて再編集する
  steps.md         後加工用の Markdown(保存のたびに上書き)
  index.html       プレビュー用 HTML(保存のたびに上書き)
  images/
    0001.png       撮影した元画像(加工しない)
    0002.png
```

- 出力先の既定はドキュメントフォルダ配下の `step_recorder`(設定で変更可)
- 画像は PNG。元画像は加工せず、強調枠やトリミングは `session.json` にデータとして持つ
- 渡すときはフォルダごと(zip など)にする

### 5.2 Markdown (`steps.md`)

- 画面ごとに見出し、画像(`images/` への相対リンク)、説明文の番号付きリスト
- 手で直して使う前提。ツールには読み戻さない(正は `session.json`)

### 5.3 HTML (`index.html`)

- 画像は `images/` を相対参照する
- 強調枠とトリミングは HTML/CSS で画像に重ねて表示する
- 画像クリックで拡大表示
- 外部 CDN を使わず、オフラインで開ける

## 6. 設定

撮影モードの初期値、画面切り替わり検知の待ち時間、ホットキー、出力先、同じ画面の扱い(手順モード/画面一覧モード)。`%APPDATA%\step_recorder\settings.json` に保存する。

## 7. 範囲外(今回はやらない)

- AI による説明文生成
