# step_recorder 仕様書

GUI アプリの操作を記録して、画像・動画つきの操作手順(HTML)を作る Windows ツール。

## 1. 全体の流れ

1. 対象(モニター、またはアプリ)を選んで記録を開始する
2. 対象を操作する。設定した撮影モードに従ってスクリーンショットと操作内容が記録される
3. 記録を停止すると編集画面が開く。削除・並べ替え・説明文の修正などを行う
4. 保存すると `session.json`(正となるデータ)とプレビュー用 HTML を書き出す
5. 後日 `session.json` をツールで開けば再編集できる
6. 編集画面の「続けて記録」で、同じ記録の続きを記録できる(3.7)

## 2. 技術構成

| 項目 | 内容 |
|---|---|
| 言語・UI | C# / WPF (.NET 10)。WPF 標準の Fluent テーマ。録画は Windows.Graphics.Capture と Media Foundation(WinRT の MediaTranscoder・MediaComposition)、Direct3D 11 は Vortice.Direct3D11 |
| 対象アプリ | WinForms / WPF (.NET) を主に想定。UI Automation で部品名を取得する |
| 配布・更新 | Velopack + GitHub Releases(public リポジトリ `taaaaaaachu/step_recorder`)。起動時に更新を確認する(設定でオフにできる)。開始画面の「今すぐ確認」で手動でも確認できる |
| 言語 | 日本語のみ |
| テスト | xUnit。記録ロジック・生成処理・JSON の読み書きを単体テストする |

## 3. 記録

### 3.1 撮影範囲

開始画面の「対象」に、モニター(「画面 2  1920×1080(メイン)」)とアプリを並べる。どちらを選んでも、撮影モード(3.2)と録画ボタンはすべて使える。

#### 3.1.1 アプリが対象

- 記録開始時に選んだアプリのウィンドウだけを撮る。同じ exe(フルパス)のプロセスは 1 つのアプリとみなす
  - 別々に起動した同じ exe も一緒に記録される
  - 中身の違うアプリが同じ exe で動く共通のホスト(ApplicationFrameHost、java、python、dotnet、cmd など。`SharedHost`)と、exe のパスが取れないプロセスは、プロセス単位
  - 選んだプロセスのウィンドウが隠れている・終了していても、同じアプリの見えているウィンドウから記録する
- 対象の一覧は、開くたびと開始画面に戻ったときに作り直す(選んだものは残す)
- 撮るのは対象アプリのウィンドウ(ダイアログや子ウィンドウも含む)。他のアプリや通知、常駐バーは写らない
- 画像はアプリ全体にする。対象アプリの見えているウィンドウ(メインウィンドウ・ダイアログ・メニューなど)を、Z オーダーの奥から順にすべて重ねて1枚にする。ウィンドウ同士の隙間は白。画面の外に置かれたウィンドウは含めない。ウィンドウは画面に見えているとおりの大きさで写す
- 操作したウィンドウ(クリックしたウィンドウ、手動撮影で撮った前面のダイアログなど)がアプリ全体より小さいときは、そのウィンドウの範囲をトリミングとして設定する。元画像はアプリ全体のまま残るので、編集画面でトリミングを外せば周りも見える

#### 3.1.2 モニターが対象

- モニターの番号は左から右(同じ列なら上から下)の順に振る(Windows の設定画面の番号とは一致しないことがある)。一覧で選ぶと、そのモニターに枠と番号を少しの間出す
- そのモニターに見えているものを丸ごと撮る(他のアプリ・タスクバー・通知も写る)
- そのモニターの上での操作を、どのアプリへのものでも記録する。クリックは押した位置、キーは前面のウィンドウが載っているモニター(またがっていれば広く載っている方)で決める。他のモニターでの操作と、step_recorder 自身への操作は記録しない
- 操作したウィンドウの範囲(モニターに載っている分)をトリミングとして設定する。範囲が取れないとき(デスクトップなど)はトリミングしない
- 手動撮影と録画ボタンは、前面のウィンドウが他のモニターにあっても、対象のモニター全体を撮る
- 画面名の初期値は操作したウィンドウのタイトル。タイトルが無ければ(タスクバーなど)「画面 2」
- 常駐バー・進み具合のウィンドウ・モニターの枠は写らない
- 制限
  - 入力内容は欄の値全体を読むので、どのアプリに打ったものも記録に残る(エディターなどでは文書の全文が入りうる)。伏せるのはパスワード欄だけ
  - UAC の画面と保護されたコンテンツは黒くなる。管理者権限のアプリへの操作は拾えない
  - 記録中の解像度の変更・切断には追従しない
  - HDR のモニターは色が変わりうる(8bit で取り込む)
  - Windows 10 では、録っている間モニターに黄色い枠が出ることがある(動画には写らない)

#### 3.1.3 共通

- マウスカーソルは既定では写さない。設定で「写す」にすると、撮影した瞬間のカーソルを画像に重ねて描く
- Per-Monitor DPI 対応。マルチモニターと拡大率の違いを考慮して座標を扱う

### 3.2 撮影モード

| モード | 撮るタイミング |
|---|---|
| クリックごと | 対象(アプリのウィンドウ、またはモニター)の上でマウスボタンを押した瞬間(クリック前の状態を撮る) |
| 手動 | ホットキーまたは常駐バーの撮影ボタンを押したとき |
| 録画 | クリックごとと同じに撮りつつ、記録の最初から最後までを動画に録る(3.6.2) |

- クリックごと・手動は記録中に常駐バーで切り替えられる。録画は記録の開始時に選ぶ(途中では切り替えない)
- どのモードでも手動撮影は常に使える
- クリック操作を記録するのは「クリックごと」「録画」のときだけ。キー入力はどのモードでも直近のステップに記録する
- 手動撮影は前面のウィンドウを撮り、そのウィンドウの範囲をトリミングにする
- ダブルクリックは新しいステップにせず、直前のクリックを「ダブルクリック」に変える

### 3.3 記録する操作情報

各ステップに以下を記録する。

- 撮影時刻、撮影モード(どの契機で撮ったか)
- ウィンドウ: タイトル、クラス名、プロセス名
- 操作した部品(取れた場合): 名前、コントロール種別、AutomationId、画像内の矩形
- クリック: ボタン(左/右/中)、ダブルクリックか、画像内の座標
- キー入力: 入力欄の名前と入力内容
  - 入力内容は部品の値(UI Automation の ValuePattern)から取る。IME で確定した日本語も取れる
  - 文字を入力した欄の値は、次のクリック・次のキー操作・入力が少し止まったとき・記録停止のいずれかで読み取る
  - 同じ欄への連続した入力は1つの操作にまとめる
  - 矢印・Home・End・PageUp・PageDown・Insert はカーソル移動とみなし、入力として扱わない
  - パスワード欄(IsPassword)は `●●●●` に伏せる
  - Enter・Tab・Esc や Ctrl+S などのショートカットは「キー操作」として別に記録する
  - ブラウザー・音量・メディアなどの専用のキーもキー操作として記録する
  - IME が開いているときの Enter・Esc は変換の確定・取消とみなし、キー操作として記録しない
  - 記録用のホットキー自体は記録しない

### 3.4 自動生成する説明文

部品情報から説明文を作る。例:

- 「『保存』ボタンをクリック」
- 「『氏名』欄に「山田太郎」と入力」
- 「Ctrl+S を押す」
- 部品名が取れない場合: 「(120, 45) をクリック」
- 手動: 空欄(編集画面で入力する)

### 3.5 記録中の操作

- 最前面に小さな常駐バーを出す(最初は対象のあるモニター(アプリならそのウィンドウがあるモニター)の上端中央。ドラッグで動かせる)。撮影モードの切替、手動撮影、録画(録画中は経過時間)、一時停止/再開、停止、撮影済み枚数がある
- 常駐バーは使っていない間、小さなタブに引っ込み、マウスを乗せると出る。ピンで留めると引っ込まない。タブで記録中・録画中・一時停止中が分かる。ホットキーは引っ込んでいても効く
- 既定のホットキー(設定で変更可)
  - 手動撮影: `Ctrl+Shift+F9`
  - 一時停止/再開: `Ctrl+Shift+F10`
  - 停止: `Ctrl+Shift+F11`
  - 録画の開始/停止: `Ctrl+Shift+F12`
- ホットキーは修飾キー(Ctrl・Alt・Shift・Win)と他のキーの組み合わせ。4つに同じキーは設定できない
- 一時停止の間は操作も動画(全編・動画のステップ)も録らない。止めていた時間は動画に入らない(前後がつながる)。手動撮影は一時停止中も使える
- 停止すると常駐バーを消し、編集画面が開くまで進み具合を出す

### 3.6 動画

- モニターが対象なら、モニター 1 枚を丸ごと録る(Windows.Graphics.Capture)。大きさと位置は録り始めたときのもの。縮小はしない
- アプリが対象なら、ウィンドウごとに録る(Windows.Graphics.Capture)ので、他のアプリや常駐バーが上に重なっても写らない。ダイアログなど同じアプリのウィンドウは、静止画と同じく Z オーダーの順に重ねる
- アプリが対象のとき、画面の大きさは録り始めたときのウィンドウで固定し、位置はそのウィンドウに追従する。はみ出したダイアログは切れる
  - そのウィンドウが隠れた・閉じた(タブの切り替え)ときは見えているウィンドウへ、別プロセスの同じ種類(ウィンドウクラス)のウィンドウが前面に来たときはそのウィンドウへ、追う相手を移す。大きさは変えないので、違う大きさのウィンドウは切れるか余白が出る
- mp4(H.264。音声は AAC 48kHz ステレオ)。フレームレートは開始画面で選ぶ(5・10・15・24・30・60fps。既定は 15)。エンコードは Windows 標準の機能(ソフトウェア)を使う
- エンコーダーには NV12 に変換してから渡す(明るさ 16〜235。幅 1024・高さ 576 までは BT.601、超えたら BT.709)。使った係数・範囲・原色を mp4 に書く
- 動画からのフレームの取り出し(ポスター、フレームのステップ、切り出し、GIF)も、デコーダーから NV12 で受け取って自前で RGB に戻す
- マウスカーソルは静止画と同じ設定で写す
- 録画している間(録画モードの全編・録画ボタンの動画)は、常に PC の音も録る(WASAPI のループバック)。使うかどうかは編集画面で選ぶ(4)
  - アプリが対象なら、録り始めたときのウィンドウのプロセスと、その子プロセスが鳴らした音だけ。モニターが対象なら PC 全体の音
  - 何も鳴っていない間は無音で埋めて、映像とずれないようにする。一時停止中の音は入らない
  - 録れなかったとき(音の出る機器が無いなど)は映像だけを録り、理由を `error.log` に残す
- Windows 10 2004 以降

#### 3.6.1 動画のステップ(録画ボタン)

- 記録中に常駐バーの「録画」かホットキーで、操作しているウィンドウ(対象がモニターならモニター全体)を録り始める。もう一度押すと止まり、その間が1つの動画のステップになる(`videos/0003.mp4`)
- 録っている間は静止画を撮らず、操作(クリック・入力・キー)を動画のステップに足して説明文にする。操作が無ければ「『画面名』の操作(動画)」。操作には、押した時点の動画上の時刻を持たせる(`operations` の `videoTime`)
- ポスター(再生前に見せる画像)は区間の最初のフレーム。強調枠は付けない。トリミングはできる
- 編集画面で区間を変えたり、2つに分けたりできる(4)。ファイルは切らずに区間(`videoStart`・`videoEnd`)だけを持ち、分けたステップは同じ mp4 を使う

#### 3.6.2 録画モード

- 開始画面の撮影モードで「録画」を選ぶと、記録の最初から最後までを1本の動画(`video.mp4`)に録る。続けて記録で録った分は別の全編の動画になる(`video-2.mp4`、`video-3.mp4`…)。`session.json` の `videos` に録った順に並べる
- ステップ(静止画)はクリックごとに撮り(手動撮影もできる)、各ステップに動画上の時刻を持たせる(`videoTime`。どの全編の時刻かは `timelineVideo`)
- 録画モードでは録画ボタンは使わない。編集画面で全編から区間を切り出す
- クリックが 1 回も無くても動画だけの記録として残る
- 動画を書けなかったときは全編の動画を記録に載せず(撮れたステップは残す)、`error.log` の場所を知らせる

#### 3.6.3 キーの表示

- 録画している間に押したキーを、1 打鍵ずつ動画上の時刻と一緒に残す(全編は `session.json` の `videos` のその動画の `keys`、録画ボタンの動画はそのステップの `keys`)。対象へのキーだけで、記録用のホットキーと一時停止中のキーは残さない
- 表記: 修飾キーと一緒なら「Ctrl+S」、文字は打った文字そのもの(IME が開いていればローマ字の打鍵)、それ以外は「Enter」「Shift+Tab」「←」など。修飾キーだけの打鍵は出さない
- パスワード欄で打った文字は「●」に伏せる
- 表示: 続けて打った文字は 1 つにまとめ、同じキーの連打は「← ×3」にまとめる。動画の下の中央に、新しいものほど下に積む

#### 3.6.4 マウスの表示

- 録画している間のクリック(左・右・中ボタン、戻る・進むボタン)とホイールを、動画上の時刻と位置と一緒に残す(全編は `session.json` の `videos` のその動画の `mouse`、録画ボタンの動画はそのステップの `mouse`)。拾うのはクリックを記録するのと同じ対象の上の操作だけで、動画の外と一時停止中は残さない
- 表示: クリックはその位置に、ボタンごとに色の違う輪と、押したボタンを塗ったマウスの絵を出す。ボタンを押したまま動かすと、マウスの絵が離すまでカーソルについていく(押している間の位置は `mouse` の `drag`)。ダブルクリックは輪が 2 つ。ホイールは回した向きの矢印を出す
- ドラッグ・カーソルの軌跡は出さない

### 3.7 続けて記録

- 編集画面の「続けて記録」を押すと、変更を保存して編集画面を閉じ、開始画面に戻る
- 開始画面の上に「「<対象名>」の記録に続けて記録します」と出る。対象・撮影モードなどは選び直せる。出力先は変えられない(その記録のフォルダに足す)。「編集に戻る」でその記録の編集画面に戻る
- 「記録開始」で記録した分は、その記録の末尾に足す。ステップの番号・画像のファイル名は前の分の続き。録画モードなら別の全編の動画になる(3.6.2)
- 対象名・記録日時・エビデンス情報(5.1.1)は最初の記録のまま
- 何も撮らずに止めても、記録は消さずに編集画面に戻る

## 4. 編集画面

- ステップの一覧(サムネイル + 説明文)と、選んだステップの画像
- 画像はズームできる(Ctrl+ホイール、ボタン、Ctrl+プラス / Ctrl+マイナス / Ctrl+0)。拡大すると縦横にスクロールでき、ホイールボタンでつかんで動かせる
- 機能
  - ステップの削除、並べ替え
  - 説明文の修正
  - 画面名(見出し)の設定。初期値はウィンドウタイトル
  - 強調枠の移動・サイズ変更・削除・追加
  - トリミング(元画像は残し、範囲だけを持つ)
  - 元に戻す(Ctrl+Z)・やり直す(Ctrl+Y)
- 同じ画面の扱い(設定で選ぶ)
  - 手順モード: 撮った順に並べるだけ。不要なものは人が消す
  - 画面一覧モード: 画面ごと(プロセス + ウィンドウクラス + 画面名)にまとめ、各画面の下に操作手順を並べる
    - 画像はその画面で最初に撮ったものを使う(使いたい画像を先頭に並べ替えて選ぶ)
    - 編集画面の一覧も、出力と同じまとまりで画面ごとに見出しを付けて区切る
- 動画の表示・再生も、書き出しと同じく自前で復号した画像を出す
- 動画のステップは「▶ 再生」で区間だけを再生する
- 動画のステップごとに再生の速さを選べる(0.25〜8 倍。`session.json` の `videoSpeed`。等速なら書かない)
  - 速さはプレーヤーで変える。編集画面の再生と HTML に反映し、mp4 は等速のまま(見る人が変えられる)。GIF だけは焼き込む
- 動画のステップごとにフレームレートを下げられる(録画したときのフレームレート以下から選ぶ。`session.json` の `videoFps`。録画したときのままなら書かない)。編集画面の再生と配布用の書き出しに反映する。保存用の HTML は録画した mp4 をそのまま再生する
- 録画ボタンで録った動画のステップを選ぶと、表示欄の下にその動画のシークバーを出す。シークバーは動画ファイル全体で、使う区間を塗る
  - 「開始位置」「終了位置」: 区間の開始・終了を今の位置にする
  - 「分割」: 今の位置で2つのステップに分ける。画面名・速さ・トリミング・キーとマウスの表示は引き継ぐ。録画中の操作は時刻で前後に分け、説明を作り直す(手で直した説明なら両方に残す)
- 録画モードの記録では、表示欄の下に全編のシークバーを出す。目盛りはステップを撮った時刻で、ステップを選ぶとシークバーもその時刻へ移る
  - 全編が 2 本以上あるとき(続けて記録した記録)は、ドロップダウン(「録画 1」「録画 2」…)でシークバーに出す全編を選ぶ
  - シークバーは時間軸を拡大できる
  - 「このフレームをステップに追加」: 今の時刻のフレームを静止画のステップにする
  - 「区間の開始」「区間の終了」「区間を動画ステップに追加」: 全編の区間を動画のステップにする(ファイルは作らず、区間だけを持つ)
  - 足したステップは時刻の順の位置に入る。画面名は直前のステップに合わせる
- 削除したステップや、使わなくなった画像・動画のファイルは、保存したときに消す(全編の動画は残す)
- 動画のステップごとに、キーの表示・マウスの表示・音声の ON/OFF を選べる(初期値は ON。`session.json` の `hideKeys`・`hideMouse`・`hideAudio`)
  - 編集画面の再生では、焼き込みと同じ見た目で重ねる。全編の表示では、記録したものをすべて重ねる
  - 全編の表示での ON/OFF は見え方だけを変え(保存しない)、そこから切り出した区間のステップの初期値になる
- 「別ウインドウで表示」で、表示欄だけを別のウインドウに出せる。別のウインドウは F か F11 で全画面にできる
- 未保存の変更があるまま閉じようとすると保存を確認する
- `StepRecorder.exe <記録フォルダ>` で起動すると、開始画面を出さずに編集画面を開く

## 5. 出力

### 5.1 フォルダ構成

```
<出力先>/20261121-174100_<対象名>/   対象名はプロセス名か「画面2」
  session.json     正となるデータ。ツールはこれを開いて再編集する
  index.html       プレビュー用 HTML(保存のたびに上書き)
  images/
    0001.png       撮影した元画像(加工しない)
    0002.png
  videos/
    0003.mp4       録画ボタンで録った動画のステップ
  video.mp4        録画モードで録った全編の動画(続けて記録した分は video-2.mp4 …)
```

- 出力先の既定はドキュメントフォルダ配下の `step_recorder`(設定で変更可)
- 画像は PNG。元画像は加工せず、強調枠やトリミングは `session.json` にデータとして持つ
- 「保存」は編集用(上の構成のまま。あとから編集を続けられる)。渡すときは「配布用に書き出す」(5.3)か、フォルダごと
- 記録中の処理で起きた例外は `error.log` に書く(記録は止めない)
- `session.json` の `targetName` が対象名(操作記録の表題に使う)

### 5.1.1 エビデンス情報

HTML の冒頭に、記録した環境の情報を表で載せる。記録開始時に自動で取り、取れなかった項目は載せない。

| 項目 | 内容 |
|---|---|
| 対象アプリ | exe のファイル名(モニターが対象なら載せない) |
| バージョン | (モニターが対象なら載せない)exe の製品バージョン(無ければファイルバージョン)。.NET の SDK が付ける "+コミット" は先頭7桁に縮める |
| 記録日時 | 記録を始めた日時 |
| PC名 | 記録した PC の名前 |
| OS | OS の名前とバージョン |
| 画面 | 対象のモニター(アプリが対象なら、そのウィンドウがあるモニター)の解像度と拡大率 |
| 記録ツール | step_recorder のバージョン |

### 5.2 HTML (`index.html`)

- 画像は `images/` を相対参照する
- 強調枠とトリミングは HTML/CSS で画像に重ねて表示する
- トリミングしている画面には「トリミングを解除」ボタンを付ける。押すと画像全体を表示し、トリミング範囲の外を暗くする
- 画像クリックで拡大表示
- 画面一覧モードで同じ画面のステップが複数あるときは、「◀ 前へ」「次へ ▶」で画面内のステップの画像を切り替えられる
- 動画のステップは `<video>` で再生する。区間はメディアフラグメント(`video.mp4#t=開始,終了`)で指定する。動画の下に「再生の速さ」の選択を出す(最初はステップに指定された速さ)。トリミングは CSS の `object-view-box`(Edge・Chrome。Firefox では全体が映る)。音声が OFF のステップは消音で始める
- 動画のステップでキー・マウスの表示が ON なら、再生に合わせてスクリプトで重ねる(動画は作り直さない)
- 外部 CDN を使わず、オフラインで開ける

### 5.3 配布用の書き出し

- 編集画面の「配布用に書き出す」で書き出す。`session.json` と全編の動画は含めない(あとから編集はできない)
  - 「フォルダに書き出す...」: 選んだフォルダに index.html と、使っている画像・動画だけを書き出す
  - 「HTML 1 ファイルに書き出す...」: 画像と動画を data: URI(base64)で埋め込んだ HTML 1 ファイルだけを書き出す(元の 4/3 倍ほどの大きさになる)
- 動画のステップは、区間・トリミング・キーとマウスの表示(GIF なら速さも)を反映したファイル(`clips/0003.mp4` かポスター `clips/0003.png`、または `clips/0003.gif`)に作り直す
- 動画の形式は書き出しボタンの横で選ぶ(MP4 / GIF)。キー・マウスの表示が ON のステップは、それを焼き込む。MP4 は、音声が ON なら区間の音を入れる(GIF は音なし)。MP4 はステップのフレームレートで作る。GIF は 10fps(ステップのフレームレートがそれより低ければそれ)、幅 960px まで、繰り返し再生
- 書き出しは裏で行い、進み具合を出す。終わると書き出した index.html を開く

## 6. 設定

撮影モードの初期値(クリックごと/手動/録画)、マウスカーソルを写すか(静止画と動画)、録画のフレームレート、ホットキー、配布用の動画の形式、出力先、同じ画面の扱い(手順モード/画面一覧モード)、自動更新のオン/オフ(既定はオン)。`%APPDATA%\step_recorder\settings.json` に保存する。
